# Instrucciones de publicación — B10-XI v1.0

## GitHub Pages

1. Crear un repositorio público para B10-XI.
2. Copiar el contenido completo de este paquete a la raíz del repositorio.
3. Mantener intactos los archivos de `documentos/`.
4. Activar GitHub Pages desde la rama/directorio elegido.
5. Confirmar que `index.html` sea accesible públicamente.
6. Registrar la URL canónica.
7. Ejecutar B10-SIT v1.0 antes de generar el QR.

## Importante

No editar el PDF/DOCX después de registrar sus hashes. Si se modifica alguno, incrementar la versión y regenerar el manifiesto.
